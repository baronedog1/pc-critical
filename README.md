# 电脑小医院 · 森林树屋

电脑监控界面的 3D 森林树屋前端原型，包含离线演示、可编辑源码、模型、处方库与后续接入文档。

先双击打开 **03_电脑小医院_森林树屋_前端模板.html** 查看效果。不需要安装依赖或启动服务器；页面运行时不依赖外网。

鼠标移到科室会显示卡片，点击可固定；拖动旋转，滚轮缩放。底部也能直接选择科室。小医生会巡诊，温度科风扇会转。上方可以切换演示状态、暂停动效或回到全景。

给本机 Coding Agent 时，请把本包一起提供，并让它读取：

1. **01_接入任务提示词.md**：沿用已选定前端，接真实电脑监控的任务说明。
2. **02_电脑小医院_处方库_V2.json**：21 个主题、43 个一段话处方。
3. **03_电脑小医院_森林树屋_前端模板.html**：可运行的样式与交互模板。

`src/` 中是可编辑源码，`models/` 中是完整场景、六科室、医生和访客的 9 个 GLB 模型。模型没有烘焙动画，巡诊与步态在源码中实现。`docs/前端接入说明.md` 说明现成接口和需要后续接入的部分。

当前是前端演示，盘名与状态都是占位内容。真实监控和后台服务尚未接入。页面只复制处方，没有系统清理操作。

已用隔离的 Chrome 浏览器验证：离线打开、六科室鼠标悬停、卡片固定、处方默认/对象替换/复制、旋转与暂停、小屏显示、无外部网络请求。QA 回执与实际页面截图放在 `verification/`、`previews/`。测试使用软件 WebGL 渲染，未对真实硬件帧率作承诺。

## 从源码构建

需要 Node.js 18 或更高版本。首次安装依赖需要联网，构建后的页面离线运行。

```sh
npm ci
npm run build
```

双击打开 `output/电脑小医院_森林树屋_前端模板.html`。仓库根目录的 `03_电脑小医院_森林树屋_前端模板.html` 是随包提供的已构建演示页。
