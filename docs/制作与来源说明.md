# 制作与来源

本次将用户选定的“森林树屋医院”概念图实现为程序化 Three.js 场景。树屋、木桥、科室道具、人物均由几何体建模，HTML 使用真实 WebGL 渲染；概念图只作为风格参考，没有作为整页背景或热点贴图代替模型。

场景、科室道具、角色与交互均包含可编辑源码。处方沿用随包 V2 资料。

Three.js 版本读取自随包源码的 `three-package.json`：`0.186.1`。文件来自官方 [Three.js 仓库](https://github.com/mrdoob/three.js) 的 master 分支，2026-10-30 下载。本包保留下载时的源文件和 SHA-256，构建不再拉取最新 master。使用的模块为核心库、OrbitControls、GLTFExporter 和 BufferGeometryUtils；许可证见 `assets/THREE-LICENSE.txt`。参考文档为 [Three.js 官方文档](https://threejs.org/docs/)。

静态几何合并与角色实例化仅用于 HTML 运行优化。完整 GLB 从原始程序化场景重新导出，保留模型层级；单科室 GLB 为渲染模型快照。所有 GLB 均完成文件头、JSON、BufferView 与 Accessor 边界检查，不包含角色动画轨道。
