# 电脑小医院 · 森林树屋前端

这是用户选定的第五版森林树屋方案的可运行三维前端。直接打开 `03_电脑小医院_森林树屋_前端模板.html`；浏览器需支持 WebGL。Three.js、交互代码和处方库都内嵌在 HTML 中，运行不请求 CDN、不上传系统数据。

## 已做好的部分

- 六个科室：内存、CPU、磁盘、温度、桌面、网络；独立房间、设备道具、木桥、树冠、接待区。
- 15 个三维医生/访客：9 位沿平台巡诊或移动，6 位在科室中轻微呼吸摆动；温度科风扇旋转。角色由独立几何体组成，脚步、手臂、头部均由 JavaScript 控制。
- 鼠标悬停显示卡片、对应模型预览及科室高亮；点击固定，关闭按钮或 Escape 关闭。底部科室按钮也可打开卡片，触屏可点选。
- 拖动以有限角度旋转，滚轮缩放，支持回到全景、暂停动效。系统开启“减少动态效果”时默认暂停三维动画。
- 21 个主题、43 个处方选项。健康/未知/未支持优先检查，异常优先对应处理；下拉切换、目标选择与复制。复制失败会选中文字供手动复制。

**当前状态、盘名和对象都是演示数据。** 没有接系统监控、进程管理、磁盘操作、文件删除、持续告警或后台服务。上方可切换演示状态。科室状态目前影响卡片标记、默认处方和底部状态点。

## 接入边界

前端保留以下全局接口；无需重建三维场景即可更新状态：

```js
window.ForestHospital.applySnapshot({
  departments: {
    memory: { status: 'healthy' },
    cpu: { status: 'warning' },
    disk: { status: 'critical' },
    temperature: { status: 'unsupported' },
    desktop: { status: 'unknown' },
    network: { status: 'healthy' }
  }
});
window.ForestHospital.selectDepartment('disk');
window.ForestHospital.getState();
```

科室 ID 固定为 `memory`、`cpu`、`disk`、`temperature`、`desktop`、`network`。状态值为 `healthy`、`warning`、`critical`、`unknown`、`unsupported`。无效状态不会覆盖原值。`applySnapshot` 只接收状态，目前不会读取数值、目标清单或阈值。接入真实数据时，在 `src/main.js` 的 `meta`、`updateTargets`、`applySnapshot` 与卡片节点中扩展真实指标和目标列表；异常判定、持续时长与恢复由本地数据层决定。

演示状态切换会重置演示状态与手动处方选择；接入后应移除或隐藏此切换器，避免覆盖真实状态。用户已选中的处方会保留到演示场景重置，可随时通过下拉切回推荐项。磁盘科目前只有“系统盘/外接盘”两个占位对象，应替换成真实盘符或挂载路径。

处方来源为 `src/prescriptions.json`，与附件 02 内容完全一致。按 `selection_policy` 推荐默认项，按 `target_kind` 获取对象，仅替换 `{{target}}`；复制时不追加监控快照、日志、JSON 或长模板。页面只复制处方。

## 源码与模型

| 文件 | 用途 |
|---|---|
| `src/scene.js` | 程序化树屋、六科室、设备道具、风扇与路线 |
| `src/characters.js` | 医生/访客建模与局部步态 |
| `src/main.js` | 灯光、镜头、巡诊路线、卡片、处方与预留接口 |
| `src/optimize.js` | 静态几何合并、动态角色实例化 |
| `src/index.template.html` | 页面结构、样式、小屏布局 |
| `assets/` | 本地 Three.js 源码与 MIT 许可证 |
| `models/scene.glb` | 完整医院场景快照 |
| `models/{科室ID}.glb` | 六个单独科室模型，已归零位置 |
| `models/doctor.glb`、`visitor.glb` | 独立医生与访客模型 |

GLB 是可复用的几何/材质快照，**未烘焙动画、未包含 HTML 卡片或镜头灯光**；动效的可编辑来源为上述 JavaScript 模块。完整场景从未合并的程序化几何导出，保留房间和角色层级，便于后续修改。HTML 自己构建场景，不需要外部加载 GLB。所有三维造型均为本次程序化建模，无第三方商用模型依赖。

## 修改和重建

仅查看模板不需要 Node 或安装依赖。需改源码时，使用 Node.js 20+，安装锁定版本的构建依赖后执行：

```bash
npm install
npm run build
```

重建文件输出至 `output/电脑小医院_森林树屋_前端模板.html`。发布给后续 Agent 时，用它更新根目录 03 文件。Three.js 已随包保存，不需要重新下载。原设备构建使用 esbuild 0.25.12；交付包的构建脚本使用项目本地 esbuild。

浏览器开启硬件加速可获得较好体验。小屏使用底部按钮选择科室，卡片收为底部半屏，局部模型预览在小屏隐藏。后台/不可见标签暂停巡诊更新；本地后端是否持续监控，交由后续接入实现。
